# Wuxia Local

Бесплатный локальный нейропереводчик игр с **английского и китайского** на русский. Готовые профили: **Wuthering Waves** (английский или китайский текст) и **Where Winds Meet (燕云十六声)**; для других игр есть профиль «Другая игра».

Программа читает субтитры и надписи с экрана, переводит их нейросетью на вашем компьютере и показывает русский текст поверх игры. Облака, подписки и интернет не нужны: интернет требуется только один раз, чтобы скачать модель.

**Безопасность аккаунта.** Программа работает как запись экрана (OBS) или экранная лупа: снимает пиксели с рабочего стола и рисует своё окно поверх. Она не внедряет DLL, не читает и не пишет память игры, не меняет её файлы, не открывает процесс игры и не нажимает клавиши за вас. Игра узнаётся только по заголовку и классу её окна. Гарантию от бана может дать только разработчик игры, но у античита здесь нечего обнаружить.

## Быстрый старт (для игрока)

1. Скачайте `WuxiaLocal-Setup-x.y.z-x64.exe` со страницы Releases и запустите. Права администратора не нужны.
   * Тип установки: **«Видеокарта (Vulkan)»** подходит почти для всех ПК. **«Только процессор»** — для старых систем.
   * Оставьте галочку **«Установить модули распознавания текста»** (английский и китайский): Windows один раз запросит подтверждение.
2. Переключите игру в режим **«Оконный без рамки» (Borderless)**. В эксклюзивном полноэкранном режиме Windows не показывает оверлеи.
3. Запустите Wuxia Local. В «Настройках → Игра» выберите игру и язык текста в ней (по умолчанию Wuthering Waves, английский). Откроется панель, и программа начнёт скачивать модель (~1,1 ГБ, один раз). Ход загрузки виден в строке «Модель».
4. Готово. По умолчанию программа сама читает весь экран и переводит всё, что похоже на речь (субтитры, реплики, подсказки), — перевод появляется под оригиналом.
5. Необязательно: **Ctrl+F7** — обвести только полосу субтитров, если хотите, чтобы программа смотрела лишь туда.

| Клавиша | Действие |
|---|---|
| **F7** | включить или выключить перевод диалогов |
| **F8** | перевести текущий экран (меню, задания, инвентарь); повторное нажатие убирает перевод |
| **F9** | показать оригинал или перевод |
| **Ctrl+F7** | выбрать область субтитров |
| **F10** | панель управления |

Клавиши меняются в `config.toml` (кнопка «Настройки» в панели). Назначенная клавиша не передаётся в игру, поэтому выбирайте свободные.

### Как улучшить перевод

* **Исправления.** В панели, в разделе «Последние реплики», поправьте перевод и нажмите «Сохранить исправление». С этого момента эта реплика всегда будет переводиться так.
* **Глоссарий.** Кнопка «Открыть глоссарий» открывает файл `user.tsv`. Формат строки: `沈七<TAB>Шэнь Ци<TAB>имя`. Термины из глоссария передаются модели вместе с репликой, поэтому имена, титулы и техники переводятся одинаково. После правки нажмите «Перечитать глоссарий».
* **Модель.** Hy-MT2 1.8B — быстрая модель по умолчанию. На мощном ПК попробуйте Hy-MT2 7B или Qwen3.5 4B. Кнопка «Сравнить модели» переводит набор тестовых реплик всеми моделями и открывает отчёт для сравнения бок о бок.
* **Распознавание.** Если OCR ошибается, включите «Повышать контраст перед OCR» или подвигайте «порог яркости текста».

### Слабый компьютер

* Перевод работает асинхронно и с пониженным приоритетом. Нейросеть берёт половину ядер CPU, вторая половина остаётся игре.
* Повторяющиеся реплики берутся из кэша мгновенно.
* Захват субтитров стоит 1–3 мс. OCR запускается только тогда, когда на экране появилась новая устоявшаяся строка.
* Если видеокарта загружена игрой, поставьте `gpu_layers = 0`: модель будет работать на процессоре.
* Модель можно запустить на **втором ПК в домашней сети**. Там запустите `llama-server --host 0.0.0.0 ...`, а здесь укажите `mode = "external"` и `external_url = "http://192.168.x.x:8080"`.

### Где лежат данные

`%LOCALAPPDATA%\WuxiaLocal`: `config.toml`, `models\`, `cache.tsv`, `corrections.tsv`, `glossary\user.tsv`, `logs\`.
Портативный режим: если рядом с exe лежит `portable.txt`, всё хранится в папке `data` рядом с программой.

## Устройство

```
crates/core   wuxia-core: чистая логика без зависимостей (тесты на любой ОС)
              text.rs        очистка OCR: пробелы между иероглифами, пунктуация, мусор по краям, имя говорящего
              detect.rs      «появилась ли новая строка»: отпечаток только по пикселям текста + стабилизация
              glossary.rs    поиск терминов (сначала самые длинные), проверка соблюдения
              prompt.rs      промпты Hy-MT (официальные шаблоны) и instruct-моделей, очистка ответа
              cache.rs       кэш и исправления: append-only TSV
              history.rs     контекст предыдущих реплик
              image.rs       масштабирование, контраст, цвет фона под надписью
crates/app    wuxia-local.exe (Windows)
              capture.rs     захват прямоугольника экрана (GDI); оверлей в захват не попадает
              ocr.rs         Windows.Media.Ocr в отдельном COM-потоке, разбиение больших кадров на тайлы
              llm/server.rs  супервизор llama-server.exe: Job Object, низкий приоритет, перезапуск, загрузка -hf
              llm/client.rs  потоковый OpenAI-совместимый клиент (вывод по мере генерации, отмена)
              translate.rs   исправления → глоссарий → кэш → модель
              dialogue.rs    цикл Dialogue Mode, отмена устаревших переводов
              interface.rs   Interface Mode: маска цвета фона + русский текст на месте надписи
              ui.rs          прозрачный оверлей (egui) + панель управления
              bench.rs       сравнение моделей на одинаковых репликах
```

Цепочка Dialogue Mode: захват (150 мс) → отпечаток текста → ждём 2 одинаковых кадра → OCR → нормализация → дубль? → исправления/кэш → глоссарий + 3 предыдущие реплики → llama-server (стриминг) → оверлей. Каждая новая реплика получает номер, а перевод предыдущей отменяется. Поэтому устаревший результат не может перекрыть новый.

## Сборка (для разработчиков)

```
cargo test -p wuxia-core              # на любой ОС
cargo build -p wuxia-local --release  # Windows 10/11 x64, MSVC
```

Для запуска из исходников положите llama.cpp (`llama-server.exe` и dll) в `target\release\llama\`, а рядом с exe — `config.default.toml`, `glossary\` и `bench\` из `assets\`.

Готовые `.exe` и установщик собирает GitHub Actions (`.github/workflows/release.yml`) при push тега `v*`.

### Известные ограничения MVP

* Только основной монитор, режим окна без рамки.
* OCR — встроенный в Windows. PaddleOCR (ONNX) запланирован как второй движок за тем же интерфейсом.
* GGUF моделей Hy-MT2 на HuggingFace требует STQ-ядро из llama.cpp PR #22836. Если версия llama.cpp из установщика не загрузит модель, CI позволяет выбрать другой тег llama.cpp (`workflow_dispatch → llama_tag`). Модели Qwen3.5 работают на обычном llama.cpp.
* Лицензии моделей (Apache-2.0 у Hy-MT2, условия Gemma у TranslateGemma) нужно перепроверить перед распространением сборок с моделями. Сейчас модели не входят в установщик и скачиваются пользователем.
