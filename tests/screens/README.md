# Проверка на снимках экрана

Каждый случай — снимок игры `имя.png` и рядом `имя.expect`: что программа должна
(и не должна) найти на снимке. Проверку запускает CI после каждой сборки
(отчёт — на странице сборки, раздел Summary), а локально:

    wuxia-local.exe --selftest tests\screens --out отчёт.md

Новый случай прямо из игры: **Ctrl+F9** — программа сохранит экран и черновик
`.expect` в `%LOCALAPPDATA%\WuxiaLocal\cases`. Черновик правится руками и
кладётся сюда вместе со снимком.

Правила `.expect` (одно в строке, `ключ<TAB>значение`, `#` — комментарий):

| Правило | Значит |
|---|---|
| `lang en` / `lang zh` | язык текста игры |
| `speech текст` | какая-то реплика содержит этот текст (ошибки OCR допускаются) |
| `speaker Имя` | у реплики отделено имя говорящего |
| `absent текст` | этого нигде нет (ни в репликах, ни в надписях F8) |
| `label текст` | F8 находит такую надпись |
| `max_speech N` | реплик не больше N |
